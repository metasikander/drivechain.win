How to read these pages

Every claim is dated
Where a number comes from a person in the project's Telegram group rather than from code or a document, the page says so — and so does the source list at the bottom of it.
Nothing is watched automatically
No cron job, no API, no feed. The pages are rewritten by hand when something changes, and the timestamp on each one is when that last happened.
Check before you act
The pages link the code, the branches and the release server behind every claim. Read those, not this.

Disclaimer — read this

These pages are vibe-coded. They were written by an AI agent, nobody has reviewed or audited them, and they can be wrong — including about the burn address, the ratios, the deadline, the block height and the pools.
